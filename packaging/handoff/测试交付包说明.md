# 测试交付包

本包用于本地 development/loopback 联调，包含 Cascade 被测产品、Ops Server 本地测试旁路和视频 worker 运行文件。

## 重要安全说明

- 包内不包含任何真实密码、Cookie、Token 或模型 API Key。
- API 配置文件只提供字段和占位符；运行前必须通过安全渠道注入联调专用 API Key。
- 请在本机创建专用测试账号。密码只在隔离的可见浏览器登录窗口中手动输入，不得写入执行包、日志、截图、录屏、字幕或结果包。
- 联调结束后删除本包解压目录，并撤销/轮换联调 API Key。

## 目录

- `cascade-product/`：被测 Cascade 项目，来源为 `D:\备份Cascade-main\Cascade-main` 的脱敏源码快照。
- `server-local-bypass/`：Server、Browser Agent 旁路说明及协议文档。
- `video-worker/`：video-worker 编译产物及 package 元数据。
- `test-docs/`：统一测试任务、执行步骤、结果检查清单和 API 配置模板。

## Cascade 启动

在 `cascade-product` 目录执行：

```powershell
npm install --legacy-peer-deps
npm run db:push
npm run dev:start
```

默认目标页面：`http://127.0.0.1:5000/app`。端口和数据库必须按本机配置修改。

## 旁路边界

旁路仅允许 development、loopback、本地可见浏览器和节点级限时 waiver。它不得修改原始 App 执行包、原包字段或哈希，不得绕过正式 Exchange 校验，也不得新增原包未声明的业务语义。
