开源讨论

Cascade DemoOps：以可验证的本地开源能力获客，以安全、算力与生产交付能力商业化。

结论

面向小用户提供非商业化、低门槛的开源版本是可行的，但不应照搬 MongoDB 的全部模式。更适合本项目的是：开源本地协议与参考能力，收费提供云端受控执行、生产安全与高成本 AI/渲染服务。

目标不是让用户手写 JSON，而是让他们能用自己的 App、代码理解 Agent 或产品知识库，按公开标准生成并审计执行包，再接入我们的 Server Browser Agent。

为什么开源

  • 降低接入门槛：外部团队知道 Server 接受什么输入、为什么会拒绝、如何在提交前自测。
  • 建立信任：用户可本地查看执行包、策略和验证器，确认 Server 不会随意改变业务目标或输入。
  • 形成统一接口：第一方 App 与第三方 Agent 都生产同一种 ClientExecutionPackage，Server 不必为每一家重写适配层。
  • 形成生态基础：行业模板、垂直 Agent、企业内部研发工具可围绕同一协议生成执行包、视频模板或验证规则。
  • 获得开发者流量：一个可本地跑通的 Demo 比单纯宣传更容易被技术用户试用、转发和贡献。
开源降低的是接入与试用成本，不降低 Server 的安全门槛。第三方生成的包仍必须经过 Schema、Hash、审批、域名、动作、凭据引用和结果验证。

开源什么

开源内容对第三方的作用对我们的作用
执行包协议知道必填字段、不可变业务事实、可修复边界与结果包格式。把 App 到 Server 的交接变成稳定标准。
Fixture（标准样例包）复制样例并替换产品 URL、Stage、控件合同和验证条件。提供联调基准与回归测试数据。
校验器在上传前发现缺字段、Hash 不一致、Stage 未对齐或安全边界错误。减少人工联调与无效请求。
本地参考运行时在自有测试站观察包会执行什么、失败在哪一步、产生哪些证据。展示受控执行能力，建立开发者信任。
基础本地视频编辑器与模板本地导入结果素材、剪辑和预览。让用户先体验结果价值，再转向云端生产能力。
后续 SDK/生成器把其代码分析 Agent、知识库或流程工具转换为标准执行包。降低第三方接入成本，推动生态扩展。

第三方如何接入

第三方自己的 App / Agent 读取产品
  -> 生成 Graph + RunSpec + Stage Plan + Script Outline
  -> 打包为 ClientExecutionPackage
  -> 使用开源校验器本地校验
  -> 用户审阅并批准
  -> 上传到我们的 Server
  -> Server Browser Agent 受约束执行、验证、录制、交付

其中，App 侧负责业务理解与审批事实；Server 侧负责受控执行、真实结果验证、局部机械修复、录制、渲染和结果交付。Server 不可改写用户意图、阶段顺序、动作类型、输入语义、secret_ref、允许域名、禁止页面或脱敏规则。

哪些能力应收费

免费/开源层商业/云端层
协议、fixture、校验器、本地 Runner、基础编辑器、基础模板。隔离浏览器执行、加密包解密、Secret Broker、受控网络出口、真实凭据使用。
本机测试站与有限本地渲染。云端录屏、批量渲染、长期素材存储、下载交付、团队协作与审计。
基础可解释模板。自动成片 Agent、风格分析、LAS/TTS/Seedance 等按量 AI 能力。
个人非商业试用与社区支持。企业网络、私有部署、SLA、合规审计与专业支持。

免费层必须限制浏览器任务次数、时长、分辨率、并发与存储；不能免费承担不可控的云浏览器、视频渲染和模型调用成本。

许可证建议

早期建议 协议、SDK、fixture、校验器和本地参考运行时优先采用 Apache-2.0，以降低企业与开发者使用顾虑。

不要一开始使用过强限制。若未来出现第三方直接托管整个开源产品、却不贡献改进的情况，再评估 AGPLv3 或商业双许可。MongoDB 当前 SSPL 并非标准开源许可，不能直接作为早期默认模板。

关键前提与风险

  • 开源部分必须可用：至少能在本地测试站完成执行、生成截图/Trace/结果包和可编辑素材，不能只开协议或空壳。
  • 安全边界必须独立：生产隔离、凭据、加密解密和企业审计不随本地开源版本开放。
  • 明确产品定位：开源版是“可验证的本地参考实现”，不是免费云执行平台。
  • 避免过早全仓开源：云端安全、未成熟商业策略和内部运维代码不应随首批开源内容发布。

建议的第一步

从主仓库拆出独立的 demoops-open-core：

  • 版本化执行包协议与 JSON Schema；
  • 成功、失败、拒绝修复等 fixture；
  • 本地校验器与命令行检查工具；
  • 本地受控 Browser Agent 参考运行时；
  • 本地测试产品站与端到端演示；
  • 基础视频编辑器示例与模板格式。

先用这一套获得开发者试用和第三方接入，再把云端执行、安全隔离、渲染和 AI 能力作为明确的商业服务。
