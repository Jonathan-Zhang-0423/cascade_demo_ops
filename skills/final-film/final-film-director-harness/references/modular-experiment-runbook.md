# Modular Experiment Runbook

1. Load the frozen ProductSpec, BuildObservationPlan, InteractionEvidencePlan, and immutable authorization budget.
2. Use only verified recording segments and temporal keyframe artifacts. Never inspect credentials or infer actions from screenshot text.
3. Bind one fresh entity, one FinalFilm job, five Browser visual calls, three Director/final visual calls, and six Provider calls to the single main leg before any external admission.
4. Resume only the entity created by the current run. Confirmed effects resume observe-only; started or uncertain effects stop at waiting input. Never adopt an old cross-run entity.
5. Product defects generate a same-entity repair directive, at most three rounds. Login-to-submit media loss invalidates the run; later chapters may be rerecorded twice.
6. Add ProductSpec, observation plan, interaction evidence, checkpoint, segment manifest, model consumption, and automation attribution to the review package.
7. Stop the main leg at final review. Any intermediate human browser action invalidates the run.
